# Cross-Signal Anomaly Detection for Enterprise AI-Agent Governance

> **Fully-synthetic disclosure.** Every agent, session, event, cost figure and
> anomaly in this repository is generated by the scripts in `code/` from fixed
> random seeds. No ServiceNow product internals, customer data, tenant
> telemetry, or proprietary system behavior is described, used, or implied
> anywhere in this repository. All generator parameters are illustrative; the
> misbehavior taxonomy is informed by public literature only (NIST AI RMF,
> OWASP LLM Top 10, public LLM-agent benchmark papers). Results are reported
> for the synthetic benchmark and should **not** be read as validated
> production impact.

## Working title

*"Cross-Signal Anomaly Detection for Enterprise AI-Agent Governance: A
Taxonomy of Agent Misbehavior Classes and a Synthetic-Telemetry Evaluation
Framework"*

## Thesis

Enterprise AI agents emit rich execution telemetry (tool calls, latencies,
token/cost accounting, escalations, permission requests). A taxonomy of agent
misbehavior classes, combined with cross-signal detectors, can flag governance
anomalies **before** policy violations complete. This repository contributes:

1. a machine-readable **telemetry event schema** (`artifacts/telemetry_event_schema.json`),
2. a **misbehavior taxonomy** of nine agent-misbehavior classes with severity
   weights and observable signals (`artifacts/misbehavior_taxonomy.json`),
3. a **synthetic telemetry generator** with parameterized anomaly injection and
   a logged ground truth (`data/anomaly_labels.csv`), and
4. a **reproducible detection benchmark** comparing four detector families
   (static rules, per-agent baselining, unsupervised outlier detection, and a
   sequence model) on per-class ROC/PR, alert cost (false positives per
   agent-day) and **detection lead time** (seconds before the violating action
   completes).

The benchmark is honest about coverage gaps: some misbehavior classes are
near-undetectable for rule-based and baselining detectors, and even the
sequence model catches only part of the behavioral-discontinuity class. The
coverage-gap heatmap is a headline artifact, not a tuning target.

## Pipeline

Run in order (Python ≥ 3.10; a `.venv` is recommended):

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

python code/generate_agents.py      # 1. agent population + task profiles  -> data/generation_metadata.json
python code/generate_telemetry.py   # 2. benign + injected sessions        -> data/synthetic_sessions.csv, data/anomaly_labels.csv
python code/evaluate.py             # 3. D1-D4 evaluation                   -> results/*.json
python code/sensitivity.py          # 4. prevalence + threshold sweeps     -> results/sensitivity.json
python code/make_figures.py         # 5. paper figures                     -> figures/*.png
```

All steps are seeded and byte-reproducible: regenerating
`data/synthetic_sessions.csv` from `seed=42` reproduces the tracked checksum in
`data/generation_metadata.json`.

## How the benchmark works

- **Agents.** 500 agents across 6 task classes, each with a per-agent
  tool-transition matrix, a declared scope set, tool permissions, a cost
  baseline and a session rate.
- **Telemetry.** Sessions are sampled from per-agent Markov chains over tools;
  latencies and token/cost draws are lognormal per tool. Benign sessions
  include routine permission requests, retries and occasional escalations.
- **Anomalies.** Nine misbehavior classes (scope creep, privilege-escalation
  attempts, runaway loops, data exfiltration, prompt-injection compromise,
  cost anomalies, silent failure masking, approval-gate circumvention,
  cross-agent collusion) are injected as parameterized mutations of benign
  sessions. Every injection is logged to `data/anomaly_labels.csv` with the
  time the violation *completes*, which makes detection lead time measurable.
- **Detectors.**
  - **D1** — static rule thresholds (the operational baseline).
  - **D2** — per-agent statistical baselining (robust z / EWMA drift per signal).
  - **D3** — Isolation Forest on session feature vectors.
  - **D4** — Markov transition-likelihood scoring over per-agent tool-call
    sequences (sequence model).
- **Metrics.** Per-class ROC/PR and AUC; false positives per agent-day at a
  fixed alert budget (operational cost of alerting); detection lead time in
  seconds before the violating action completes; and a class × detector
  coverage-gap heatmap.

## Results (principal run: seed 42, 49,377 sessions, 985 injected anomalies)

Headline comparison on the held-out evaluation split (19,755 sessions) at the
headline alert budget of **0.1 false positives per agent-day**; thresholds are
calibrated out-of-sample (75% fit / 25% threshold-calibration within the
calibration split). Full numbers: `results/evaluation.json`,
`results/coverage_gap.json`, `results/operating_points.json`,
`results/sensitivity.json`; figures in `figures/`.

| Detector | ROC-AUC | PR-AUC | Recall | Precision | FP/ad | Lead time (pre-viol. rate / median) |
| --- | --- | --- | --- | --- | --- | --- |
| D1 static rules | 0.890 | 0.686 | 0.625 | 0.738 | 0.115 | 0.48 / 21.9 s |
| D2 per-agent baseline | **0.934** | **0.786** | **0.702** | **0.748** | 0.123 | **0.70 / 21.2 s** |
| D3 isolation forest | 0.900 | 0.547 | 0.410 | 0.676 | 0.102 | 0.31 / 11.2 s |
| D4 Markov sequence | 0.629 | 0.116 | 0.078 | 0.298 | 0.095 | 0.10 / 12.7 s |

Coverage-gap matrix (per-class recall at 0.1 FP/agent-day; ROC-AUC in
parentheses) — see `figures/fig1_coverage_gap_heatmap.png`:

| Class | D1 | D2 | D3 | D4 |
| --- | --- | --- | --- | --- |
| Scope creep | 0.48 (0.81) | 0.59 (0.95) | 0.02 (0.82) | 0.04 (0.50) |
| Privilege-escalation attempts | 0.55 (0.91) | 1.00 (0.98) | 0.35 (0.96) | 0.02 (0.52) |
| Runaway loops | 0.93 (0.98) | 1.00 (0.99) | 0.72 (0.98) | 0.05 (0.65) |
| Data exfiltration | 1.00 (0.999) | 1.00 (0.99) | 1.00 (0.998) | 0.30 (0.84) |
| Prompt-injection compromise | 0.01 (0.47) | 0.01 (0.51) | 0.01 (0.49) | 0.02 (0.66) |
| Cost anomalies | 0.22 (0.94) | 1.00 (0.99) | 0.86 (0.98) | 0.03 (0.52) |
| Silent failure masking | 0.85 (0.93) | 0.43 (0.92) | 0.05 (0.83) | 0.00 (0.48) |
| Approval-gate circumvention | 0.87 (0.92) | 0.56 (0.93) | 0.48 (0.97) | 0.18 (0.74) |

Sensitivity (`results/sensitivity.json`): recall at the fixed alert budget is
prevalence-invariant across 0.5–10% anomaly prevalence (D2: 0.69–0.72); the
coverage ranking is seed-stable for D1–D3 (Spearman 0.95–1.00 across seeds
101/202/303, class-level AUC drift ≤ 0.065) and noisier for D4 (0.72–0.78,
low-recall regime); a −30% threshold mis-setting raises D2 recall to 0.83 but
its alert cost to 0.46 FP/agent-day (≈4× budget).

## Limitations

- Fully synthetic telemetry with illustrative parameters; no production
  validation is claimed or possible from this repository alone.
- The generator encodes its own anomaly signatures, so detector performance is
  an upper bound on what the same detectors would achieve on real telemetry
  (see `paper/main.tex`, Limitations & Disclosure).
- Some classes (behavioral-discontinuity prompt injection, cross-agent
  collusion) are deliberately kept subtle and are only partially covered; the
  gaps are reported rather than tuned away.
